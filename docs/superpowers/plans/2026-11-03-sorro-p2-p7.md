# Sorro P2–P7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Sorro's frame, assistant, side panel, notebooks and note types, calendar and tasks upgrades, and the News tab.

**Architecture:** Next.js static export; data through Supabase with RLS and the `lib/offline.ts` mutation queue; new server work as Supabase Edge Functions (Deno). Shared widget components feed both Home's widget strip and the right panel. Pure logic (parsers, reducers, tool argument validation) lives in `lib/*.ts` with a `*.check.ts` beside it.

**Tech Stack:** Next.js 15, React 19, TanStack Query, Tiptap 3, Supabase (Postgres, Edge Functions), Gemini API, `@huggingface/transformers`, Tauri 2, Capacitor 8.

**Spec:** `docs/superpowers/specs/2026-11-03-sorro-p2-p7-design.md`

## Global Constraints

- Tokens only: every colour and font through `app/tokens.css`; no literal colour past the token block (Hallmark floor 1).
- Never `transition: all`; animate transform and opacity only. Springs `--float`, `--drift`, `--snap`. Motion switch is the `.nomo` class (W1, W2).
- No eyebrows, no tracked-caps labels except the SORRO wordmark (W3), no decorative dots, no gradients, no glass, no emoji, no invented numbers.
- `data-part` on every new region; codes added to `lib/parts.ts`.
- Breakpoints: phone < 600px, tablet 600–1024px, desktop > 1024px.
- Tap targets ≥ 44px on phone; fixed bars reserve their height plus `env(safe-area-inset-*)`.
- New tables are `sorro_*` with RLS `user_id = auth.uid()`; every mutation registered with `defineMutation()` at module scope.
- New browser-side hosts go in both CSPs (`vercel.json`, `app/layout.tsx`): `api.open-meteo.com`, `geocoding-api.open-meteo.com`, the Hugging Face hosts already present.
- Secrets never in client code; Gemini key stays in Edge Function secrets.
- Commits: sentence case, no prefix, no co-author trailer. Push to master after each part passes its checks (Jhems: ship every session).

## Review Focus

1. **Assistant writes without consent:** a tool call that creates or completes something must show its result card with Undo, and Undo must reverse it (Task 6 test).
2. **News drop abuse:** a wrong or missing key must write nothing and reveal nothing; parts out of order or repeated must assemble once (Task 1 tests).
3. **Old note types still open:** document pages, journals, boards, Java files saved before P5 open in their new type without data loss (Task 10 test on real saved bodies from `lib/*.check.ts` fixtures).
4. **Phone bar covering content** on Calendar and the note editor at 390px, including with the on-screen keyboard open (Task 3 browser check).
5. **Natural-language add misreads** a date into the past or the wrong weekday across the Asia/Manila zone (Task 11 and 12 tests force `TZ=America/New_York`, per memory `dev-machine-timezone-has-no-dst`).
