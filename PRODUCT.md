# Basedly

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The primary user uses Basedly on both phone and desktop for calendar planning, tasks, and note-taking.

## Product Purpose

Make daily planning and thinking easy to return to. Calendar, Tasks, and Notes are the primary workflows. Notes includes normal writing, freestyle whiteboards, graph/schema notes, a journal, and Java notes.

## Operating Context

Next.js web app with a Capacitor Android wrapper and Supabase sync. Existing personal content and functional workflows must survive the redesign.

## Capabilities and Constraints

Existing secondary areas include projects, habits, gym, food, money, community, files, and people. Make them discoverable without overwhelming the three primary workflows. Investigate slow loading, sharing, and connections to other apps. Static export and Android compatibility remain required.

## Brand Commitments

Basedly name. The user requests a cute minimal circle buddy in onboarding and lively animations. No visual style or theme preference has been chosen.

## Product Principles

- Put useful actions and readable content first.
- Reveal additional features in context.
- Preserve work and make loading, saving, errors, and recovery visible.
- Design mobile and desktop together.

## Accessibility & Inclusion

Improve visibility, spacing, readable labels, touch targets, keyboard access, and reduced-motion behavior.

## Evidence on Hand

User interview on 2026-09-08. Existing implementation, HANDOFF.md, and browser verification. User explicitly requests build verification, browser inspection, commit, and push to live.
